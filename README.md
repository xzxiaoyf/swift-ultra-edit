# SwiftUltraEdit

#### 介绍
借助 AI 写了一个自己用的文本编辑器支持 16 进制编辑。SWIFT 语言实现，在 MAC 上运行，没有签名。

#### 软件架构
软件架构使用SWIFT语言编写，只能在 MAC 上运行，支持 Intel 和 ARM 架构。
